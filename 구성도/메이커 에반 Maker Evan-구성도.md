## 핵심 요약

**1. 문제 제기 — AI는 기억을 못 한다**
- AI에게 어제 설명한 내용을 오늘 또 처음부터 설명해야 함. 대화가 끝나면(채팅창을 닫으면) 지식이 쌓이지 않고 사라짐.
- 예시: 회사 자료 20개가 있을 때, "프로젝트 어떻게 진행되고 있어?"라고 매번 물으면 AI는 그때마다 20개 전부를 다시 읽어야 함 → 어제 읽은 걸 기억 못 함.
- 이로 인한 두 가지 비용: ① 토큰 낭비(=비용 증가) ② 속도 저하(자료가 많을수록 느려짐).

**2. 카파시(前 테슬라 AI팀)의 해법 — LLM 위키**
- 비유: 도서관 사서. 책이 들어올 때마다 사서는 요약 카드를 만들어 두고, 나중에 질문이 오면 책 전체가 아니라 요약 카드만 봄.
- LLM 위키 = AI가 파일을 읽을 때마다 매번 처음부터 읽지 않고, 한 번 읽은 내용을 위키(위키피디아 형태) 페이지로 정리해 두는 방식. 개념별 페이지, 페이지 간 연결 존재.
- 새 자료가 들어오면 AI가 기존 위키 페이지를 업데이트하거나 새 페이지를 생성. 이후 질문에는 원본 파일이 아니라 위키만 참조.
- 핵심 문장: "유지보수 비용이 거의 제로에 가깝다" — 인간은 위키 유지·정합성 관리에 지쳐 포기하지만, AI는 지치지 않고 반복 업데이트를 계속 수행함.
- 구조는 3요소로 단순함: ① 원본 파일 ② AI가 만든 위키 ③ 위키 운영 방법을 지시하는 CLAUDE.md.

**3. 카파시 방식의 한계**
- 질문할 때마다 AI가 여전히 원본 파일을 뒤져야 함(목차 → 관련 파일 탐색 → 전체 읽기). 소스가 많아질수록 느려지고 토큰도 계속 소모됨.

**4. Graphify — 지식 지도 자동화 도구**
- 파일들을 자동 분석해 지식 지도를 생성. 분석 방식 2가지:
  - **구조 분석**: 파일 내용을 빠르고 정확하게 훑는 방식.
  - **의미 분석**: 여러 서브 에이전트(AI 보조 일꾼)가 동시에 문서(+이미지 포함)를 읽어 개념 간 관계를 추출.
- 결과물: `graph.json` + 위키 폴더가 자동 생성됨.
- 한 번 만든 지식 지도는 재사용 가능 — 파일이 바뀌면 바뀐 부분만 재처리, 변화 없으면 기존 지도를 그대로 사용(전체 재처리 불필요).

**5. 토큰 절감의 핵심 — GRAPH_REPORT**
- 원본 파일 7개를 직접 읽는 대신, `GRAPH_REPORT` 요약 페이지 1장 + 관련 노드 2~3개만 읽으면 됨(노드 = 개념 하나를 담은 카드).
- 보고된 절감 효과: **최대 71.5배 토큰 절감**.
- `GRAPH_REPORT`에는 핵심 개념, 개념 간 묶음, 어떤 질문에 답할 수 있는지까지 요약되어 있음 → AI는 질문 시 이 요약 페이지를 먼저 보고 관련 노드만 추가로 읽음.

**6. 관계 지도의 특징**
- Graphify의 노드는 단순 연결이 아니라 **관계의 종류**까지 표시: "이걸 바탕으로 만들었다", "이걸 참조한다", "이게 근거다" 등.
- 덕분에 AI가 답변할 때 근거까지 함께 제시 가능.
- **신뢰도 등급** 제공: 원본에 명시된 내용(확실) > 합리적으로 추론한 내용(중간) > 불확실한 내용(낮음). AI가 답변 시 확실한 내용과 추론한 내용을 구분해서 말할 수 있음.
- 관련 개념을 자동으로 그룹핑 → 질문받으면 관련 그룹만 확인, 전체를 다 볼 필요 없음.
- 자료가 쌓일수록(새 노드가 기존 지도에 연결될수록) 지식 지도가 풍부해지고 AI 답변 품질이 계속 상승 — "복리 성장" 구조.

**7. 실제 구축 방법 (카파시 방식, 최소 구성)**
- 필요한 건 폴더 + 텍스트 파일뿐.
  - `raw` 폴더: 원본 파일(기사, 논문, 이미지 등) 저장.
  - `wiki` 폴더: AI가 만든 위키 파일 저장.
  - `CLAUDE.md`: "새 파일이 들어오면 위키를 업데이트해" 같은 지시문 기록.
- 이후 AI에게 "이거 처리해 줘"라고 요청하면 위키 문서 10~15개를 알아서 업데이트.
- 질문 시 AI는 `INDEX.md`(목차)를 먼저 확인한 뒤 관련 페이지만 읽고 답변.

**8. Graphify를 더한 확장 구성**
- 파일이 많거나 이미지가 섞여 있으면 Graphify가 `graph.json` + 위키 폴더 + 전체 요약 페이지를 자동 생성.
- `CLAUDE.md`에 "질문 전에 요약 페이지 먼저 봐" 한 줄만 추가하면, AI가 매 질문 전 자동으로 지도부터 탐색.
- 완성되면: 몇 개월간 읽은 자료 전체가 위키로 정리되고, 그 위키를 기반으로 질문에 답하며, 새 자료가 들어오면 자동 업데이트되는 "나만의 지식 비서"가 됨.

**9. 주의 사항**
- Graphify 사용 시 CLAUDE.md에 `grep` 같은 명령어를 쓰지 말라고 명시적으로 요청해야 함.
- 대신 반드시 `GRAPH_REPORT`(json) 파일을 먼저 읽고 관련 노드만 읽으라고 지시해야 함.
- CLAUDE.md에 세세한 프롬프팅만 되어 있으면 이후 프로세스는 문제없이 작동.

**10. 전체 정리**
- 카파시의 LLM 위키 개념(한 번 만든 위키를 재사용)이 핵심.
- Graphify가 이를 자동화 — 파일을 분석해 `graph.json`으로 지식 지도 생성.
- 효과: 토큰 최대 71.5배 절감, 속도 향상, 자료가 쌓일수록 답변 품질이 복리로 향상.
- 구현 난이도는 낮음 — 폴더와 텍스트 파일, CLAUDE.md 한 줄이면 충분.
