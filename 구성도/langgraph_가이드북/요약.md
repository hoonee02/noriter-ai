# LangGraph 가이드북 — 전체 요약

> 출처: WikiDocs "LangGraph 가이드북 - 에이전트 RAG with 랭그래프 [ver 1.0+]" (판다스 스튜디오)
> https://wikidocs.net/book/16723 · 수집일: 2026-07-19

## 이 책은 무엇을 다루는가

LangGraph 프레임워크로 상태 기반(State) 워크플로우를 설계하는 기초부터, 도구를 사용하는 ReAct 에이전트,
RAG(검색 증강 생성) 시스템, 여러 에이전트가 협력하는 다중 에이전트 아키텍처까지 — "LLM으로 복잡한
의사결정 시스템을 만드는 법"을 단계적으로 다루는 실습형 가이드북이다. Part 0(글쓴이 소개)을 제외하면
4개 Part, 총 40개 이상의 세부 절로 구성되어 있다.

## Part별 핵심 요약

**Part 1. LangGraph 기초** — State(공유 데이터, 리듀서로 병합 전략 지정) · Node(파이썬 함수, 변경된
필드만 반환) · Edge(일반/조건부/Command/Send)라는 세 요소로 그래프를 조립하고 `compile()`→`invoke()`로
실행하는 기본기를 다진다. 여기에 체크포인터(메모리·Time Travel·Durable Execution), 서브그래프(모듈화),
스트리밍(5가지 모드), 그리고 보일러플레이트를 줄여주는 Functional API(`@entrypoint`/`@task`)까지
LangGraph의 저수준 구성 요소 전체가 이 Part 하나에 응축돼 있다. 이후 모든 Part는 이 State/Node/Edge
어휘로 설명된다.

**Part 2. ReAct 에이전트 구현** — "생각→행동→관찰"을 반복하며 도구를 호출하는 ReAct 패러다임을 소개하고,
`create_agent`(빠른 구현)와 `StateGraph`(세밀한 제어) 두 방식으로 직접 구현한다. 여기에 위험한 행동을
사람이 승인하게 하는 Human-in-the-Loop(`interrupt()`+`Command(resume=...)`)와, 결정론적 규칙→LLM
심사→HITL 세 겹으로 쌓는 Guardrails(안전장치)까지 다뤄, "믿을 수 있는 도구 사용 에이전트"를 만드는
전체 과정을 완성한다.

**Part 3. RAG 시스템 구축** — 문서 로딩·청킹·임베딩·벡터 DB 저장이라는 데이터 파이프라인부터, 쿼리 확장·
하이브리드 검색 같은 검색 최적화, `StateGraph`로 구현하는 기본/고급 RAG 패턴(Multi-Query, HyDE,
Self-RAG), RAG를 에이전트의 도구로 통합하는 Agentic RAG, 그리고 RAGAS 기반 정량 평가·성능 최적화까지
RAG 시스템의 처음부터 끝까지를 다룬다.

**Part 4. 다중 에이전트 시스템 구현** — 도구가 늘어날수록 커지는 단일 에이전트의 한계를 짚고,
Subagents(Supervisor가 워커 에이전트들을 도구처럼 호출·조율)와 Handoffs(대화 상태에 따라 담당 에이전트가
전환) 두 핵심 패턴을 고객 지원 시나리오 등 실전 예제로 구현한다.

## 전체 결론

이 책의 서사는 "그래프의 최소 단위(State/Node/Edge) → 그 위에 도구 사용을 얹은 ReAct 에이전트 →
지식 검색을 얹은 RAG → 여러 에이전트의 협업"으로, 뒤로 갈수록 앞 Part의 구성 요소를 재료 삼아 더 복잡한
시스템을 쌓아 올리는 구조다. 즉 Part 4의 다중 에이전트 시스템은 결국 Part 1의 State/서브그래프,
Part 2의 도구 호출·HITL, Part 3의 RAG 도구화가 조합된 결과물이라고 볼 수 있다.

## 기존 정리 문서와의 연결

`구성도/RAG_개념_확장.md`와 `구성도/하이브리드_에이전트_RAG.md`가 Hierarchical RAG·Agentic RAG·Graph
RAG 같은 **개념과 아키텍처 설계**를 다뤘다면, 이 책의 Part 3(RAG 시스템 구축)은 그 개념들이 LangGraph
코드로 어떻게 구현되는지 보여주는 **실제 구현체**에 해당한다. 특히 Part 3-3-3(RAG + ReAct 에이전트
통합)에서 다룬 "`@tool`로 감싼 지식 검색 함수를 에이전트가 스스로 호출 여부를 판단해 사용하는" 패턴은
`하이브리드_에이전트_RAG.md`에서 개념적으로 정리한 Agentic RAG(검색을 에이전트의 판단에 맡기는 방식)의
LangChain/LangGraph 코드 레벨 구현과 정확히 일치한다. 또한 Part 3-3-2의 Multi-Query·Self-RAG 패턴은
`RAG_개념_확장.md`에서 다룬 반복적·자기평가형 검색 전략이 `StateGraph`의 조건부 엣지로 구현되는 구체적
사례로 볼 수 있다. 결과적으로 이 책은 기존 개념 문서들의 "왜"에 "어떻게(코드)"를 더해주는 실습 보완재
역할을 한다.
