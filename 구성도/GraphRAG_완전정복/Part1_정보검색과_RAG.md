## 1-1. 왜 검색 기술이 중요한가?
원본: https://wikidocs.net/319187

- 키워드 검색(구글식)은 빠르지만 "가성비 좋고 데이트하기 좋은 이탈리안 레스토랑" 같은 복합 조건 질의에서는 맥락·관계를 이해하지 못해 한계를 드러낸다.
- 기업 환경에서는 문제가 더 심각하다. 정보가 포털/드라이브/이메일/메신저/회의록/암묵지 등으로 흩어져 있고, 가치 있는 정보일수록(암묵지, 회의 내용) 검색이 더 어려워지는 역설이 있다. 직장인은 근무시간의 상당 부분을 정보 탐색에 소비한다는 조사도 인용된다.
- ChatGPT 이후 AI는 "질문 응답" 대신 "대화형 이해"로 검색 패러다임을 바꿨다. 의미 기반 이해(동의어·완곡 표현 처리)가 가능해졌다.
- 그러나 LLM 단독으로는 한계가 있다: 학습 데이터 시점 이후 정보 부재, 환각(그럴듯한 오답 생성), 사내/개인 데이터 미보유.
- 이 한계를 보완하기 위해 등장한 것이 RAG(Retrieval-Augmented Generation)이며, 다음 절부터 본격적으로 다룬다.

## 1-2. LLM과 검색의 만남 - RAG 이해하기
원본: https://wikidocs.net/319188

- LLM의 3대 한계를 재확인: (1) 지식 컷오프 — 학습 시점 이후 사건은 모름, (2) 환각 — 실존하지 않는 판례를 인용해 미국 변호사가 징계받은 사례처럼 "정답을 아는 게 아니라 그럴듯한 다음 단어를 생성"하는 구조적 위험, (3) 개인화 불가 — 일반 지식은 답하지만 특정 회사·제품 맥락에는 대응 못함.
- RAG = Retrieval(검색) + Augmented(증강) + Generation(생성)의 결합. 저자는 이를 "암기만 하는 사람 vs 책을 찾아 확인하고 답하는 도서관 사서"에 비유해 설명한다.
- RAG 구성요소 3가지
  - 지식 저장소(Knowledge Base): 사내 문서, 매뉴얼, FAQ 등 원천 데이터
  - 검색 시스템(Retriever): 질문과 관련된 문서를 찾아내는 역할(도서관 카탈로그에 해당)
  - 생성 모델(Generator): 검색된 문서를 바탕으로 자연어 답변을 생성하는 LLM
- 동작 흐름: 사용자 질문 → 검색(Retrieval) → 지식 저장소 조회 → 질문+검색결과 결합(Augmentation) → LLM 답변 생성(Generation).
- RAG의 장점: 재학습 없이 지식 저장소만 갱신하면 최신 정보 반영, 실제 문서 근거로 환각 감소, 출처 제시 가능, 도메인 특화 맞춤형 AI 구현 가능.

## 1-3. RAG에서 GraphRAG로의 진화
원본: https://wikidocs.net/319190

전통적 RAG(청크 단위 벡터 검색)도 완전하지 않다. 이 절은 그 한계를 세 가지로 짚고 GraphRAG의 필요성을 제시한다.

- **점(點) 검색의 한계**: "김철수의 팀장은 누구?"처럼 여러 문서(직원-팀-팀장)에 흩어진 사실을 연결해야 하는 질문에서, 유사도 검색은 "김철수"가 언급된 문서 하나만 찾아오고 연결고리(개발팀 → 팀장 박영희)를 놓친다.
- **맥락 단절**: 문서를 청크로 쪼개면 대명사·생략된 주어("이 회사")가 가리키는 대상이 다른 청크에 있어 검색이 실패하는 경우가 생긴다.
- **다중 홉(Multi-hop) 추론 불가**: "AI 프로젝트 담당 팀의 2020년 이후 입사자는?"처럼 여러 단계의 연결 추론이 필요한 질의는 벡터 유사도만으로 풀 수 없다.
- 해결책은 **지식 그래프**: 정보를 노드(개체)와 엣지(관계)로 표현하면 "김철수→개발팀→박영희" 같은 경로 탐색이 자연스러워지고, 관계의 의미(소속, 담당 등)가 명시적으로 남는다.
- **GraphRAG**의 핵심 아이디어는 전통 RAG의 벡터 검색 위에 그래프 탐색을 결합하는 것. "관계 질의", "경로 탐색", "조건을 만족하는 전체 집합 조회", "계층 구조 질의" 등에서 전통 RAG 대비 강점을 가진다는 비교표가 제시된다.
- 활용 사례로 고객 서비스(구매이력 → 제품 → 호환액세서리 → 할인정보 경로 탐색), 기업 지식관리(팀 → 프로젝트 → 기술스택 → 교육자료), 논문 탐색(인용 관계 그래프)을 든다.
