## 이 책이 다루는 것

Deep Agents는 LangChain 프레임워크 위에서 동작하는 자율 AI 에이전트 시스템으로, 단순 질문-답변
챗봇을 넘어 파일시스템을 직접 관리하고, 세션을 넘어 유지되는 장기 메모리를 갖고, 복잡한 작업을
서브에이전트에 위임하며, 필요할 때 사람의 승인을 받는 다단계 작업 수행 에이전트를 만드는 방법을
`create_deep_agent()` API 중심으로 다룬다. Part 4는 Claude Code/Codex CLI + LangChain Docs MCP
기반의 "바이브 코딩" 방식 실전 프로젝트 10개로 구성된다.

- Part 1: 핵심 아키텍처 — 고수준/저수준 API, 미들웨어 아키텍처, 백엔드 시스템, AGENTS.md & Skills
- Part 2: 실전 핵심 기능 — 파일시스템 도구, 서브에이전트 설계, 장기 메모리, Human-in-the-Loop,
  비동기 스트리밍, Context Engineering, MCP 도구 연동, 비동기 서브에이전트
- Part 3: 고급 커스터마이징 — 커스텀 미들웨어, 모델 선택/비용 최적화, 요약 미들웨어, CLI/원격
  샌드박스, 디버깅/프로파일링, 파일시스템 권한 제어, 코드 실행 샌드박스, 배포와 에디터 통합
- Part 4: 실전 프로젝트 10개 (바이브 코딩 방식)

## 우리 `구성도/` 문서들과 맞닿는 지점

### 1. 서브에이전트 위임 ↔ 다중 에이전트 시스템
"복잡한 작업을 서브에이전트에게 위임한다"는 설계는 [langgraph_가이드북/Part4_다중에이전트.md](langgraph_가이드북/Part4_다중에이전트.md)의
Supervisor/Handoffs 패턴, 그리고 [에르메스_에이전트_핵심개념.md](에르메스_에이전트_핵심개념.md)의
역할형(조사/정리/실행) 에이전트 분업과 같은 축의 문제(하나의 에이전트가 모든 걸 처리하지 않고
역할을 나눠 협업시키는 것)를 LangChain 코드 레벨(`create_deep_agent()`)에서 구현한 사례로 볼 수 있다.

### 2. 장기 메모리(Store Backend) ↔ LLM 위키
세션을 넘어 정보를 보존하는 장기 메모리 구현은, 우리가 정리한 [구성도.md](구성도.md)·
[LLM위키_완벽가이드/](LLM위키_완벽가이드/)의 "대화가 끝나면 사라지는 지식을 어떻게 영속화할
것인가"라는 문제의식과 정확히 같은 축이지만, 이 책은 이를 사람이 관리하는 위키 문서가 아니라
에이전트 프레임워크 내부의 Store Backend(코드 수준의 저장소)로 구현한다는 점이 다르다.

### 3. Context Engineering ↔ Hierarchical RAG의 컨텍스트 구성
"에이전트에 정보를 제대로 공급하기"라는 Context Engineering 절의 문제의식은, [하이브리드_에이전트_RAG.md](하이브리드_에이전트_RAG.md)에서
다룬 "무엇을 언제 컨텍스트로 넣을지"(요약 우선 탐색, 부모-자식 청크 등)의 설계 원칙과 직접 연결된다.

### 4. MCP 도구 연동 ↔ 도구함(Tool Definition)
외부 도구 서버를 MCP로 붙이는 부분은, [하이브리드_에이전트_RAG.md](하이브리드_에이전트_RAG.md)의
"검색 기능을 함수(Tool)로 추상화한다"는 오케스트레이션 레이어 개념, 그리고
[에르메스_에이전트_핵심개념.md](에르메스_에이전트_핵심개념.md)의 외부 도구/채널 연동과 같은 패턴이다.

### 5. Human-in-the-Loop ↔ LangGraph 가이드북
HITL 패턴은 [langgraph_가이드북/Part2_ReAct_에이전트.md](langgraph_가이드북/Part2_ReAct_에이전트.md)에서
이미 다룬 `interrupt()` 기반 승인 워크플로우와 동일한 개념으로, 이 책은 이를 Deep Agents API
관점에서 다시 다룬다.

## 결론

이 책은 지금까지 우리가 정리한 "지식을 어떻게 위키로 쌓고(LLM위키), 에이전트 조직을 어떻게
운영하고(에르메스 에이전트), 그래프/RAG로 어떻게 검색할 것인가(GraphRAG·하이브리드 에이전트)"라는
개념들을, LangChain의 Deep Agents 프레임워크라는 구체적 코드 레벨 구현체로 보여주는 사례에
가깝다 — 특히 서브에이전트 위임, 장기 메모리, MCP 도구 연동, HITL은 앞서 정리한 여러 문서의
개념이 실제 API로 어떻게 구현되는지 보여주는 지점이다. 세부 구현이 필요하면 위 원본 링크에서
관심 있는 Part를 직접 확인하는 것을 권한다.
